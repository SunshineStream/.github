# SunshineStream

SunshineStream is the planned GitHub home for **Sunshine**, LizardByte's self-hosted game stream host for Moonlight.
It is a project organization under [LizardByte](https://github.com/LizardByte), with the same shared community.

## Coming to this organization

[Sunshine](https://github.com/LizardByte/Sunshine) will move from `LizardByte/Sunshine` to
`SunshineStream/Sunshine` once migration preparations are complete. Until then, use the current repository
for development, issues, downloads, and releases.

The planned project website is `sunshine.lizardbyte.dev`. The website transition and repository transfer
will happen in stages, with project links updated as each step is ready.
